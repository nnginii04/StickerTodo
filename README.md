# 스티커 투두 (StickerTodo)

맥 바탕화면에 포스트잇처럼 붙여두는 할 일 앱. 할 일은 Apple 미리 알림에 저장되어 아이폰과 자동으로 동기화돼요.

## 실행하기

필요한 것: macOS 14 이상, 명령줄 도구 (Xcode 전체는 없어도 돼요)

```bash
# 1) 명령줄 도구 설치 (Homebrew를 쓰고 있다면 이미 깔려 있어요)
xcode-select --install

# 2) 이 폴더로 이동해서 빌드 + 실행
cd StickerTodo
chmod +x build.sh
./build.sh

# 응용 프로그램 폴더에 설치하려면 (로그인 시 자동 실행을 쓰려면 이렇게 설치해야 해요)
./build.sh --install
```

처음 실행하면 미리 알림 접근 권한을 물어봐요. 허용하면 첫 스티커가 기본 미리 알림 목록과 연결돼요.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 스티커 옮기기 | 제목 줄을 잡고 끌기 |
| 크기 조절 | 오른쪽 아래 모서리 끌기 |
| 스티커 설정 | 오른쪽 위 `⋯` 버튼 (목록 연결, 스타일, 정렬, 위에 띄우기, 삭제) |
| 새 스티커 | 메뉴바 아이콘 → 새 스티커 |
| 할 일 추가 | 스티커 아래 입력칸, 또는 어디서든 `⌃⌥T` |
| 완료 | 동그라미 클릭 (줄 긋고 연하게, 24시간 뒤 사라짐) |
| 이름 수정 | 할 일 더블클릭 |
| 우선순위, 마감일, 삭제 | 할 일 우클릭 |
| 순서 바꾸기 | 정렬이 "직접 정렬"일 때 드래그 |

### 빠른 입력 문법

입력할 때 아래 단어를 띄어서 쓰면 자동으로 적용돼요.

- `오늘`, `내일`, `모레` → 마감일
- `!` 낮음, `!!` 보통, `!!!` 높음 → 우선순위

예: `보고서 제출 내일 !!` → "보고서 제출", 마감 내일, 우선순위 보통

## 알아두기

- 스티커 하나는 미리 알림 목록 하나와 연결돼요. 스티커를 지워도 목록과 할 일은 남아 있어요.
- 드래그로 바꾼 순서는 이 앱 안에만 저장돼요. (미리 알림 앱이 순서를 외부에 공개하지 않아서)
- 다시 빌드하면 서명이 바뀌어서 미리 알림 권한을 한 번 더 물어볼 수 있어요.
- 스티커 설정은 `~/Library/Application Support/StickerTodo/stickers.json`에 저장돼요.

## 파일 구조

```
Sources/StickerTodo/
  StickerTodoApp.swift          앱 시작점, 메뉴바 메뉴
  AppController.swift           스티커 창, 빠른 추가, 단축키 관리
  StickerWindowController.swift 스티커 창 (바탕화면 모드 / 위에 띄우기 모드)
  StickerView.swift             스티커 화면과 할 일 한 줄
  QuickAdd.swift                ⌃⌥T 빠른 추가 창
  RemindersService.swift        Apple 미리 알림 연동
  StickerStore.swift            스티커 설정 저장
  Models.swift                  데이터 구조, 날짜/우선순위, 입력 해석
  AppKitViews.swift             유리 배경, 창 이동/크기 조절, 대화상자
  HotKey.swift                  전역 단축키
```
